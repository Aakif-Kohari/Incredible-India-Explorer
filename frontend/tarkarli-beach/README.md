# 🏝️ Tarkarli Beach: Konkan's Crystal Coast

## Overview
A dedicated explorer for **Tarkarli Beach**, Maharashtra's premier scuba diving destination on the Konkan coast. Known for crystal-clear waters with 20-foot visibility, coral reefs, and vibrant Malvani culture.

## Features
- **Konkan Context:** Six cards explaining the unique characteristics of the Konkan coastline.
- **Marine Activities:** Scuba diving, snorkeling, backwater kayaking, dolphin watching.
- **Malvani Culture:** Traditional cuisine (Sol Kadhi, Fish Curry Rice) and cultural festivals.
- **Nearby Attractions:** Sindhudurg Fort, Rameshwar Temple, Tsunami Island.

## File Structure
- `index.html`: Semantic layout with five tabbed sections.
- `style.css`: Tropical turquoise theme with full dark/light mode support.
- `script.js`: Tab management, lightbox modal, Journey API integration.
- `data.js`: Comprehensive datasets for Konkan features, activities, cuisine, and traditions.
- `components.js`: Safe DOM rendering functions (zero innerHTML).

## Accessibility
- Fully keyboard navigable tabs and gallery.
- ARIA attributes for screen readers.
- High contrast ratios in both light and dark themes.
