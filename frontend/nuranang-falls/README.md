# 🏔️ Nuranang Falls (Sela Region) Explorer

## Overview
An interactive, geographically verified page for **Nuranang Falls** (often misnamed Jang Falls or Sela Waterfall). Located in the Tawang district of Arunachal Pradesh, this 100m cascade is fed by the glacial melt of the Sela Pass.

## Features
- **Identity Verification:** Clarifies the official name and geographic coordinates.
- **Elevation Visualizer:** Animated altitude profile comparing the falls to Sela Pass and Tawang.
- **Route Explorer:** Step-by-step timeline of the journey from Assam through the Eastern Himalayas.
- **Himalayan Seasons:** Details the extreme winter freeze and summer glacial melt.

## File Structure
- `index.html`: Semantic layout with elevation and route tabs.
- `style.css`: Himalayan ice blue theme with animated elevation bars.
- `script.js`: Tab management, Journey API, and IntersectionObserver.
- `data.js`: Altitude, seasonal, and route datasets.
- `components.js`: Safe DOM rendering functions.
