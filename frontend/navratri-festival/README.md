# 🪔 Navratri: Nine Nights of Indian Tradition

## Overview
An interactive explorer for **Navratri**, India's nine-night festival celebrating the divine feminine energy (Shakti). This page documents the nine forms of Goddess Durga (Navadurga), diverse regional traditions, and the vibrant cultural practices of Garba, Dandiya, and Durga Puja.

## Features
- **Nine Nights Grid:** Color-coded cards for each Navadurga form with daily colors, offerings, and flowers.
- **Regional Traditions:** Interactive map and cards showing celebrations across Gujarat, Bengal, South India, North India, and Maharashtra.
- **Garba & Dandiya Explorer:** Detailed breakdown of the two iconic dance forms.
- **Cultural Guide:** Traditional fasting foods (vrat ka khana) and festive attire.

## File Structure
- `index.html`: Semantic layout with four content tabs.
- `style.css`: Festive maroon/gold theme with full dark/light mode support.
- `script.js`: Tab management, map interactions, Journey API integration.
- `data.js`: Comprehensive datasets for all nine nights and regional traditions.
- `components.js`: Safe DOM rendering functions (no innerHTML).

## Accessibility
- Fully keyboard navigable tabs and gallery.
- ARIA attributes for screen readers.
- High contrast ratios in both light and dark themes.
- Focus indicators on all interactive elements.
