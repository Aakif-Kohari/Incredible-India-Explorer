# 🌲 Usri Falls Explorer

## Overview
An interactive explorer for **Usri Falls**, a hidden three-stream cascade in the Giridih district of Jharkhand. This page details its geological setting, seasonal transformations, and the surrounding deciduous forests of the Chota Nagpur Plateau.

## Features
- **Geographic Breakdown:** Detailed cards explaining the gorge, streams, and granite boulders.
- **Seasonal Comparison:** Visual guide to the falls during Monsoon, Winter, and Summer.
- **Nearby Attractions:** Guide to Parasnath Hill, Khandoli Dam, and Madhuban.

## File Structure
- `index.html`: Semantic layout with tabs for Overview, Geography, Seasons, and Nearby.
- `style.css`: Forest green and granite theme with responsive grids.
- `script.js`: Tab management, Journey API, and IntersectionObserver.
- `data.js`: Structured datasets for geography and seasons.
- `components.js`: Safe DOM rendering functions.
