# 🌊 Chandipur Beach: The Vanishing Sea

## Overview
A dedicated explorer for **Chandipur Beach**, Odisha's unique hide-and-seek beach where the sea recedes up to 5 kilometers during low tide, allowing visitors to walk on the exposed sea bed.

## Features
- **Tidal Phenomenon:** Visual comparison of high vs low tide states.
- **24-Hour Tidal Chart:** Animated CSS-based visualization of tidal cycles.
- **Ecology Section:** Six cards covering intertidal zones, casuarina groves, and marine life.
- **Activities:** Six unique experiences from sea bed walking to beach driving.
- **Nearby Attractions:** DRDO Test Range, Panchalingeswar Temple, Balasore town.

## File Structure
- `index.html`: Semantic layout with five tabbed sections.
- `style.css`: Ocean blue theme with full dark/light mode support.
- `script.js`: Tab management, lightbox modal, Journey API integration.
- `data.js`: Comprehensive datasets for tides, ecology, activities, and gallery.
- `components.js`: Safe DOM rendering functions (zero innerHTML).

## Accessibility
- Fully keyboard navigable tabs and gallery.
- ARIA attributes for screen readers.
- High contrast ratios in both light and dark themes.
