# Cyclone Remal, 2024 — Field Profile & Meteorological Analysis

An in-depth, interactive multimedia field profile documenting **Severe Cyclonic Storm Remal (May 2024)**, the first named tropical cyclone of the 2024 North Indian Ocean season.

## Features
- **Key Storm Metrics**: 135 km/h peak wind gusts, 207,060+ West Bengal evacuees, and IMD 5-day lead-time forecasting performance.
- **Interactive Bay of Bengal Storm Track**: Vector SVG schematic tracking the system from low-pressure genesis to Sagar Island/Khepupara landfall and Northeast India dissipation.
- **Hour-by-Hour Timeline**: Key milestones spanning the 5-day storm life cycle from 23 May alert to landfall on 26–27 May.
- **West Bengal & Sundarbans Impact Grid**: Detailed breakdown across South/North 24 Parganas, Kolkata rainfall (260 mm), and mangrove buffer shielding.
- **Saline Inundation & Embankment Analysis**: Overtopping analysis at 67 points across Gosaba and low-lying delta settlements.
- **Wind & Rain Intensity Bar Chart**: Animated visualization of sustained wind vs peak gusts vs rainfall volume.
- **Interactive Coastal Impact Map**: 8 interactive pinpoint locations across West Bengal coastal blocks.
- **Interactive Knowledge Check Quiz**: 4-question interactive widget with instant feedback and score tracking.
- **Dark / Light Mode & Responsive Design**: Theme switching with `localStorage` memory and full keyboard accessibility.
- **Schema.org Structured Data**: JSON-LD `Article` and `Event` schemas for semantic SEO.

## File Structure
- `index.html`: Semantic HTML5 markup, SVG track & impact maps, structured data.
- `style.css`: Responsive CSS with dark/light themes, typography, and card layouts.
- `script.js`: Interactive engine for track/impact map readouts, bar chart observer, and quiz engine.
- `README.md`: Module documentation and overview.
