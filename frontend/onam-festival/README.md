# 🌼 Onam Festival Explorer

## Overview
An interactive page dedicated to **Onam**, the grand harvest festival of Kerala. This explorer documents the legend of King Mahabali, the 10-day celebration timeline, the magnificent Onam Sadya feast, and vibrant cultural traditions like Vallam Kali and Pookalam.

## Features
- **10-Day Timeline:** A chronological guide to the Atham through Thiruvonam days.
- **Traditions Grid:** Detailed cards explaining Pookalam, Vallam Kali, Thiruvathira, and Pulikali.
- **Interactive Sadya Explorer:** A clickable menu allowing users to explore the 26+ dishes of the traditional feast.
- **Visual Gallery & Map:** Lightbox-enabled images and a CSS-based map of Kerala's celebration hubs.

## File Structure
- `index.html`: Semantic layout with ARIA roles.
- `style.css`: Kerala-inspired theme (Kasavu Gold, Forest Green) with dark/light mode.
- `script.js`: Event handling, Journey API integration, and lightbox logic.
- `data.js`: Structured datasets for timeline, traditions, and food.
- `components.js`: Safe DOM rendering functions (no innerHTML).

## Accessibility
- Fully keyboard navigable tabs and gallery.
- ARIA attributes for screen readers.
- High contrast ratios in both light and dark themes.
