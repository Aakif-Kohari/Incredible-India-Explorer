# 🥾 Nag Tibba Trek: The Serpent's Peak

## Overview
A comprehensive trek guide for **Nag Tibba**, the highest peak in Uttarakhand's Nag Tibba Range at 3,022 meters. This beginner-friendly trek offers breathtaking panoramic views of major Himalayan peaks including Bandarpoonch, Swargarohini, and Gangotri ranges.

## Features
- **Interactive Elevation Profile:** Animated chart showing altitude progression from Pantwari (1,500m) to Summit (3,022m)
- **Detailed Trail Segments:** 4 trail sections with distance, duration, and detailed descriptions
- **Difficulty Assessment:** 6-parameter assessment with visual progress bars
- **Scenic Viewpoints:** 4 major viewpoints with descriptions and best viewing times
- **Visible Peaks List:** 8 major Himalayan peaks visible from the summit with altitudes
- **Campsite Information:** 3 campsite options with facilities and descriptions
- **Packing Essentials:** 6 categories of essential items for the trek
- **Nearby Attractions:** 6 villages and attractions to extend your trip
- **Image Gallery:** 12 captioned images with lightbox modal

## File Structure
- `index.html`: Semantic layout with 6 tabbed sections
- `style.css`: Alpine green theme with responsive grid layouts and animations
- `script.js`: Tab management, lightbox modal, Journey API integration
- `data.js`: Comprehensive datasets for all trek information
- `components.js`: Safe DOM rendering functions (zero innerHTML usage)
- `metadata.json`: Trek metadata for search and indexing
- `README.md`: This documentation file

## Trek Details
- **Location:** Tehri Garhwal District, Uttarakhand
- **Base Camp:** Pantwari Village (1,500m)
- **Summit Altitude:** 3,022m
- **Total Distance:** 16 km round trip
- **Duration:** 2 days (can be done in 1 day by fit trekkers)
- **Difficulty:** Easy to Moderate
- **Best Season:** March to June, September to November

## Accessibility Features
- Fully keyboard navigable tabs and gallery
- ARIA attributes for screen readers
- High contrast ratios in both light and dark themes
- Focus indicators on all interactive elements
- Descriptive alt text for all images
