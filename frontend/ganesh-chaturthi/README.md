# 🐘 Ganesh Chaturthi: India's Ganesh Festival

## Overview
An interactive explorer for **Ganesh Chaturthi**, the grand 10-day festival celebrating Lord Ganesha. This page documents the festival's historical roots (Lokmanya Tilak's 1893 movement), famous pandals across India, the complete 10-day timeline, idol-making traditions, and modern eco-friendly initiatives.

## Features
- **Famous Pandals Explorer:** Detailed cards for 6 iconic pandals including Lalbaugcha Raja, Dagdusheth, and Khairatabad with visitor stats and history.
- **10-Day Timeline:** Complete day-by-day breakdown from Pranapratishtha to Visarjan.
- **Idol-Making Traditions:** Documentation of Shadu Mati clay techniques and sacred proportions.
- **Eco-Friendly Section:** Comprehensive guide to sustainable celebrations (seed Ganesha, natural colors, artificial tanks).
- **Traditional Foods:** Modak, Karanji, Puran Poli, and other naivedya offerings.

## File Structure
- `index.html`: Semantic layout with five tabbed sections.
- `style.css`: Festive red/saffron theme with full dark/light mode support.
- `script.js`: Tab management, map interactions, Journey API integration.
- `data.js`: Comprehensive datasets for pandals, timeline, and foods.
- `components.js`: Safe DOM rendering functions (zero innerHTML usage).

## Accessibility
- Fully keyboard navigable tabs and gallery.
- ARIA attributes for screen readers.
- High contrast ratios in both light and dark themes.
- Focus indicators on all interactive elements.
