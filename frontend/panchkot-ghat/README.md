# 👑 Panchkot Ghat: Royal Heritage on the Varanasi Riverfront

## Overview
A comprehensive explorer for **Panchkot Ghat**, showcasing the role of the Panchkot royal family in shaping Varanasi's distinctive riverfront architecture. This ghat demonstrates how regional royalty contributed to the sacred city's spiritual and architectural landscape through patronage.

## Features
- **Historical Timeline:** 6-period timeline from 1800s to 2000s documenting royal patronage
- **Royal Heritage:** 6 features showcasing palace-inspired design and cultural patronage
- **Royal Contributions:** 6 areas of contribution including financial endowments and architectural legacy
- **Palace Architecture:** 6 distinctive features including ornate facades and balconied windows
- **Architectural Details:** 6 construction and decorative elements
- **Associated Temples:** 6 temples within the ghat complex
- **Ghat Network:** 6 aspects of integration with neighboring ghats
- **Comprehensive Timeline:** 10 events from 1780s to 2000s
- **Image Gallery:** 12 captioned images with lightbox modal

## File Structure
- `index.html`: Semantic layout with 8 tabbed sections
- `style.css`: Royal purple/gold theme with responsive grids
- `script.js`: Tab management, lightbox, Journey API integration
- `data.js`: Comprehensive datasets for all sections
- `components.js`: Safe DOM rendering (zero innerHTML)
- `metadata.json`: Structured metadata
- `README.md`: Documentation

- **City:** Varanasi, Uttar Pradesh
