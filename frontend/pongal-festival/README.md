# 🌾 Pongal Festival Explorer

## Overview
An interactive page dedicated to **Pongal**, the four-day harvest festival of Tamil Nadu. This explorer documents the distinct traditions of Bhogi, Thai Pongal, Mattu Pongal, and Kaanum Pongal, along with Kolam art and traditional delicacies.

## Features
- **4-Day Timeline:** A visual grid breaking down the specific rituals of each day.
- **Kolam & Decor:** Detailed cards explaining the ecological and spiritual significance of threshold art.
- **Interactive Food Explorer:** A clickable menu allowing users to explore Sakkarai Pongal, Ven Pongal, and other festive dishes.
- **Visual Gallery & Map:** Lightbox-enabled images and a CSS-based map of Tamil Nadu's celebration hubs.

## File Structure
- `index.html`: Semantic layout with ARIA roles.
- `style.css`: Terracotta and Turmeric theme with dark/light mode.
- `script.js`: Event handling, Journey API integration, and lightbox logic.
- `data.js`: Structured datasets for timeline, traditions, and food.
- `components.js`: Safe DOM rendering functions (no innerHTML).

## Accessibility
- Fully keyboard navigable tabs and gallery.
- ARIA attributes for screen readers.
- High contrast ratios in both light and dark themes.
