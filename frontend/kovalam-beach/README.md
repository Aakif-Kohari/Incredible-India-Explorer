# 🏝️ Kovalam Beach Explorer

## Overview
An interactive page dedicated to **Kovalam Beach**, Kerala's premier coastal destination. This explorer details its three distinct crescent-shaped beaches, local water sports, Ayurvedic wellness retreats, and the vibrant fishing community.

## Features
- **The 3 Beaches:** Detailed cards for Lighthouse, Hawah, and Samudra beaches.
- **Activities Grid:** Showcasing Ayurveda, water sports, catamaran cruises, and coastal cycling.
- **Visual Gallery & Map:** Lightbox-enabled images and a CSS-based map pinpointing the three bays.

## File Structure
- `index.html`: Semantic layout with ARIA roles.
- `style.css`: Coastal Ocean Blue and Sand theme with dark/light mode.
- `script.js`: Event handling, Journey API integration, and lightbox logic.
- `data.js`: Structured datasets for beaches, activities, and gallery.
- `components.js`: Safe DOM rendering functions (no innerHTML).

## Accessibility
- Fully keyboard navigable tabs and gallery.
- ARIA attributes for screen readers.
- High contrast ratios in both light and dark themes.
