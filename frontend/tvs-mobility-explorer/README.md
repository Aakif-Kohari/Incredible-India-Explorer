# TVS Mobility Explorer — Issue #2628

This folder implements **TVS: Explore India's Mobility Brand** for the Incredible India Explorer project.

## Included

- TVS origin and historical context
- Major mobility and manufacturing milestones
- Interactive searchable/filterable timeline
- Two-wheeler product evolution
- TVS Racing history and track-to-road narrative
- Brand identity section
- Product detail modal
- Light/dark theme switcher
- Responsive mobile layout
- Keyboard and reduced-motion accessibility considerations

## Files

- `index.html` — semantic page structure and content
- `style.css` — responsive visual system and illustrations
- `script.js` — timeline filtering, product filtering, modal interactions, theme persistence and navigation behavior

## Run locally

Open `index.html` in a browser, or serve the `frontend` directory with a simple static server:

```bash
npx serve frontend/tvs-mobility-explorer
```

## Content references

The historical milestones were cross-checked against TVS Motor Company material, including:

- TVS Motor Company history and investor material
- TVS Racing's official history
- TVS Motor Company Apache and racing publications

The page is an educational presentation for the Incredible India Explorer project and does not claim to be an official TVS website.
