# The 1999 Odisha Super Cyclone — Interactive Profile

An in-depth, interactive multimedia feature documenting the **1999 Odisha Super Cyclone (BOB 06)** — the most intense tropical cyclone ever recorded in the North Indian Ocean basin (912 hPa central pressure, 260 km/h sustained winds) — and Odisha's subsequent transformation into a global benchmark for disaster risk reduction.

## Features
- **Key Meteorology Statistics Grid**: 260 km/h wind speeds, 912 hPa barometric collapse, 5–8m storm surge, and 950mm torrential rainfall metrics.
- **Interactive Barometric Pressure Gauge**: SVG circular gauge showing barometric pressure drop from 1005 hPa to 912 hPa with replay trigger.
- **Chronological Storm Track Timeline Slider**: 6-stage interactive timeline tracing the system from its Andaman Sea depression to landfall and dissipation.
- **Interactive Coastal Impact Map**: Vector SVG map of Odisha highlighting 7 coastal districts (Jagatsinghpur, Kendrapara, Bhadrak, Balasore, Cuttack, Puri, Ganjam).
- **Meteorological Anatomy Explorer**: Interactive tabbed breakdown of the Eye Vortex, Eyewall Core, Spiral Rainbands, and Oceanic Heat Engine.
- **Storm Surge Simulator**: Elevation slider/buttons visualizing coastal seawater inundation (1.5m to 8.0m peak).
- **Cyclone Scale Comparison Matrix**: IMD Super Cyclonic Storm vs Saffir-Simpson Category 5 vs Beaufort Force 12.
- **Institutional Rebuild Accordion**: Chronicle of OSDMA founding (Dec 1999), 879+ multi-purpose shelters, 100,000+ volunteer cadre, and Early Warning Dissemination System (EWDS).
- **Comparative Mortality Chart**: Visualizing 99.5% fatality reduction from 1999 (9,887) to Phailin 2013, Fani 2019, and Dana 2024.
- **Interactive Safety & Meteorology Quiz**: 4-question interactive quiz widget with immediate feedback and scoring.
- **Accessibility & Theme Toggle**: Smooth Dark / Light mode switching with localStorage persistence and full keyboard accessibility.
- **Schema.org Structured Data**: JSON-LD Article and Event metadata for semantic SEO and accessibility.

## File Structure
- `index.html`: Main document with semantic HTML5, SVG map, structured data, and layout.
- `style.css`: Responsive CSS with custom properties, dark/light themes, card glassmorphism, and animations.
- `script.js`: Interactive logic for timeline slider, district map, surge simulator, pressure gauge, and quiz widget.
- `README.md`: Profile documentation and technical overview.
