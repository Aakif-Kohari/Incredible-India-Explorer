# The Megalithic Heritage of India — Interactive Explorer

An interactive digital archaeological profile documenting the prehistoric **Megalithic Heritage of India (c. 1500–500 BCE to ongoing living traditions in Meghalaya)**.

## Features
- **Interactive Geospatial Field Map**: Leaflet.js-powered map plotting 9 major megalithic sites across 7 Indian states with custom SVG pins and category filtering.
- **Architectural Typology Field Key**: Vector SVG diagrams and archaeological descriptions for Menhirs, Port-hole Dolmens/Cists, Cairn Circles, Topikal/Kudaikal Umbrella Stones, Terracotta Urn Burials, and Living Monoliths.
- **Material Culture & Grave Goods Showcase**: Detailed analysis of Iron Age metallurgy, Black-and-Red Ware ceramics, etched carnelian beads, and equestrian grave goods.
- **Regional Variations Matrix**: Comparative regional analysis spanning Vidarbha (Maharashtra), Karnataka, Andhra/Telangana, Tamil Nadu, Kerala, and Northeast India.
- **Site Register Index**: Comprehensive catalog of Hirebenkal, Brahmagiri, Junapani, Mahurjhari, Adichanallur, Nilgiri Toda Cairns, Marayur Muniyara, Ariyannur, and Nartiang.
- **Interactive Knowledge Check Quiz**: 4-question interactive widget with instant feedback and score calculation.
- **Dark / Light Mode & Responsive Design**: Custom CSS variables, texture overlay, sticky navigation, and mobile-friendly touch targets.
- **Schema.org Structured Data**: JSON-LD Article and Place schemas for semantic SEO.

## File Structure
- `index.html`: Semantic HTML5 markup, Leaflet integration, structured data.
- `style.css`: Earthy color palette, responsive grid systems, card typography, and theme styling.
- `script.js`: Leaflet map markers, filter logic, typology renderers, and quiz engine.
- `README.md`: Module documentation and overview.
