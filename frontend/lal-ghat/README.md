# 🧱 Lal Ghat: A Distinctive Corner of the Ganga Riverfront

## Overview
A comprehensive explorer for **Lal Ghat**, one of Varanasi's lesser-known but historically significant ghats. Known for its distinctive red sandstone architecture, this ghat offers an intimate experience of the sacred city's spiritual life along the eternal Ganga.

## Features
- **Historical Timeline:** 5 key periods from 1700s to 2000s documenting the ghat's evolution
- **Historical Facts:** 6 detailed facts about the ghat's origins, naming, and development
- **Architecture Documentation:** 6 architectural features including red sandstone steps, retaining walls, and decorative elements
- **Physical Layout:** 4 components showing the ghat's spatial organization from upper landing to river interface
- **Temple Information:** 6 associated religious structures with descriptions and significance
- **Religious Practices:** 6 traditional practices including morning snan, sandhya aarti, and pind daan
- **Riverfront Activities:** 6 traditional activities from boat rides to artistic sketching
- **Daily Rituals:** 6 time-based rituals throughout the day from Brahma Muhurta to night observances
- **Neighboring Ghats:** 6 nearby ghats with relationships and context
- **Image Gallery:** 12 professionally captioned images with lightbox modal

## File Structure
- `index.html`: Semantic layout with 7 tabbed sections
- `style.css`: Heritage red/stone theme with responsive grids and animations
- `script.js`: Tab management, lightbox modal, Journey API integration
- `data.js`: Comprehensive datasets for all ghat information
- `components.js`: Safe DOM rendering functions (zero innerHTML usage)
- `metadata.json`: Structured metadata for search and indexing
- `README.md`: This documentation file
