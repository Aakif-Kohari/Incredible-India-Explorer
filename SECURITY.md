# Security Policy

Thank you for helping keep **Incredible India Explorer** secure. We appreciate the efforts of security researchers and contributors in identifying and responsibly disclosing vulnerabilities.

## Supported Versions

The following versions are currently supported with security updates:

| Version | Supported |
| ------- | --------- |
| Latest (main) | ✅ Yes |
| Older releases | ❌ No |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly instead of creating a public GitHub issue.

You can report vulnerabilities by:

- Opening a private security advisory (if enabled).
- Contacting the project maintainers directly via email or the project's official communication channel.

Please include:

- A detailed description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.
- Suggested mitigation (if available).

## Response Process

After receiving a report, we aim to:

- Acknowledge the report within **3–5 business days**.
- Investigate and validate the issue.
- Work on a fix as quickly as possible.
- Notify the reporter once the issue has been resolved.

## Responsible Disclosure

Please:

- Do not publicly disclose vulnerabilities before they are fixed.
- Give the maintainers reasonable time to investigate and resolve the issue.
- Avoid accessing, modifying, or deleting data that does not belong to you.

## Security Best Practices

Contributors are encouraged to:

- Keep dependencies up to date.
- Follow secure coding practices.
- Avoid committing sensitive information such as API keys or credentials.
- Validate user input wherever applicable.
- Report any suspected security issues responsibly.

Thank you for helping make **Incredible India Explorer** a safer project for everyone.
